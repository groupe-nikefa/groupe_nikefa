# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-21

### Added
- Initial release of GROUPE NIKEFA medical supply marketplace app
- Multi-platform support: Android, iOS, Web
- Bilingual support: Arabic (RTL) and French (LTR)
- User authentication with Supabase Auth (email/password)
- Role-based access: customer and admin roles
- Account types: individual, hospital, laboratory
- Product catalog with search and category filtering
- Product detail with image carousel, variant selection, and bulk pricing
- Shopping cart with guest and authenticated modes
- Cart synchronization on login (guest cart merges with server cart)
- Checkout flow with Cash on Delivery (COD)
- Order history with real-time status tracking
- Order cancellation for pending orders
- Reorder functionality for delivered orders
- Admin dashboard with product, category, and order management
- Inventory management with low-stock alerts
- Offline detection with non-intrusive banner
- Password reset via email
- Product sharing via clipboard URL copy
- User profile management
- Local notifications support
- Image compression for product uploads
